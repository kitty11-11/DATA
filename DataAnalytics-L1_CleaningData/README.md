# Employee Data Cleaning

## Objective
Clean and preprocess an employee dataset using Python and Pandas.

## Dataset
The dataset contains employee information such as:
- Employee ID
- Name
- Age
- Department and Region
- Status
- Join Date
- Salary
- Email
- Phone
- Performance Score
- Remote Work

## Data Cleaning Performed
- Checked for missing values
- Checked for duplicate records
- Cleaned text columns
- Converted Join Date to datetime format
- Standardized phone numbers to 10 digits
- Checked email formats
- Checked age and salary values
- Checked categorical columns
- Saved the cleaned dataset as a CSV file

## Tools Used
- Python
- Pandas
- Jupyter Notebook
- VS Code

## Files
- `Task2_Data_Cleaning.ipynb` – Data cleaning notebook
- `Cleaned_Employee_Dataset.csv` – Cleaned dataset
